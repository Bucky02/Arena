# 🏟️ app_campi

> **Progetto di EMAD** | L'app definitiva per la prenotazione e la gestione dei campi sportivi.
>
> ⚽ 🥎 🏀 🏐 🏉 🎾

Un'applicazione mobile sviluppata in Flutter pensata per connettere sportivi e gestori di impianti. Semplifica la ricerca delle disponibilità e l'organizzazione delle partite in modo intuitivo e veloce.

---

## ✨ Caratteristiche Principali

* **Ricerca Multisport:** Filtra i campi disponibili per Calcio, Tennis, Padel, Basket, Pallavolo o Rugby.
* **Prenotazione Rapida:** Seleziona la data, l'orario e blocca il tuo campo in pochi tap.
* **Gestione per Proprietari:** Un'interfaccia dedicata per gestire le prenotazioni in entrata e aggiornare lo stato dei campi.
* **Cross-platform:** Esperienza fluida e nativa sia su dispositivi Android che iOS.

## 🛠️ Tecnologie Utilizzate

* **Frontend:** [Flutter](https://flutter.dev/) & Dart
* **Backend:** *Supabase*
* **Ambienti di Sviluppo:** Android Studio / VS Code
